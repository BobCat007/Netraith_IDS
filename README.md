# 🛡️ Netraith IDS

Netraith IDS is a real-time hybrid Intrusion Detection System that combines rule-based detection with machine learning (Isolation Forest) to detect network attacks such as SYN Flood, ICMP Flood, Port Scan, and anomalies.

## 🚀 Features
- Real-time packet capture using Scapy
- Hybrid detection (Rule + AI)
- Live dashboard using Flask + SocketIO
- Attack logging and visualization
- Detection of multiple attack types

## 🧠 Tech Stack
- Python
- Scapy
- Flask + SocketIO
- Scikit-learn
- Chart.js

## 📊 Detection Capabilities
- SYN Flood
- ICMP Flood
- Port Scan
- DDoS
- Anomaly Detection
